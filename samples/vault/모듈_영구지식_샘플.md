## 📌 핵심 내용 (CCIA)

### Context (맥락)
에이전트 시스템에 복잡한 자율성을 부여할수록 '땜질식 규칙 추가'로 인해 시스템 복잡도가 폭증하고 컨텍스트 오염이 일어난다.

### Core (핵심)
자연스러운 단일 데이터 흐름(No-Patchwork Flow)을 설계하고, 모든 쓰기 작업을 단일 게이트웨이(`vault_io`)로 통제해야 규칙 개수를 최소화하면서도 100% 무결성을 유지할 수 있다.

### Insight (통찰)
"규칙을 계속 늘리지 말고, 데이터가 흐르는 파이프라인 자체를 비가역적이고 안전하게 만들어라."

### Action (실행)
1. AI가 생성하는 변경점은 항상 `Proposal(제안)` 상태로 격리한다.
2. 디스크 쓰기는 사용자가 화면에서 Diff를 눈으로 확인하고 승인했을 때만 단일 관문을 통해 실행한다.
