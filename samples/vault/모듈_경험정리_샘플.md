다중 쓰기 지점으로 인한 파일 깨짐과 환각 수치 문제를 단일 관문 게이트웨이 및 원문 대조 엔진으로 해결한 리팩토링 경험.

## 📌 핵심 경험 (STAR)

> [!QUOTE] 원문 컨텍스트
> AI 코파일럿이 대화 중에 사용자 확인 없이 파일을 덮어쓰거나, 원문 메모에 없는 지표를 임의로 지어내는 문제가 있었습니다.

### Situation (상황)
초기 프로토타입 단계에서 기능별로 직접 파일을 수정하다 보니, 외부 편집과의 충돌 및 인위적 수치 생성(환각) 문제가 발생함.

### Task (과제)
기존 코드를 건드리지 않고도 모든 파일 쓰기를 단일 관문으로 수렴시키고, 원문에 없는 수치를 100% 감지하는 검증 파이프라인 구축.

### Action (행동)
1. **단일 관문 모듈 구축**: `vault_io.safe_write`를 구현하여 원자적 쓰기(`.tmp` ➔ `os.replace`) 및 타임스탬프 기반 자동 백업(`.subrain_history/`) 강제.
2. **Fact Guard 엔진 개발**: 정규표현식으로 한국어 조사를 분리하고, 원문 인용구와 제안 수치를 실시간 대조하여 위반 시 빨간 경고 칩 표시.
3. **시각적 Diff 뷰어 구현**: 웹 콕핏 화면에 LCS 기반 줄 단위 비교기를 탑재하여 사용자가 직접 확인 후 승인하도록 유도.

### Result (결과 및 교훈)
- 쓰기 실패율 및 파일 충돌 0건 달성.
- 원문 외 수치 날조 발생 시 실시간 감지율 100% 확보.
- 교훈: 시스템의 안전성은 규칙의 개수가 아니라 데이터 흐름의 구조적 불변식에서 비롯된다.
