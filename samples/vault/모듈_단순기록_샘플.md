# 단순 메모 예시

## 1. 한 줄 요약
모바일 이동 중에 빠르게 떠오른 생각이나 할 일 등을 인박스에 즉시 남겨두는 임시 메모 형태.

> [!QUOTE] 원문 컨텍스트
> 회의 중 떠오른 아이디어: 클립보드 복사 내용 중 URL이 포함되어 있으면 메타태그(og:title, og:description)를 자동 인출하여 카드에 덧붙여주는 기능이 있으면 좋겠다.

## 📌 메모 내용
- 인입 시 자동으로 `type: Fleeting`으로 분류됨.
- 추후 정식 문서로 발전시키고 싶을 때 대시보드 코파일럿에서 "영구지식으로 구조화해줘"라고 지시하면 CCIA 구조로 재편성 가능.
